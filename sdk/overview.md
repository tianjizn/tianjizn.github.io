# SDK 概述

## 架构说明

天机机器人 SDK 提供两套开发接口：

### Python SDK

- **文件位置**: 
- **依赖**: Python 3.8+
- **适用场景**: 快速原型开发、数据分析、机器学习集成

### C++ SDK

- **文件位置**: , 
- **依赖**: C++ 编译器 (GCC/Clang/MSVC)
- **适用场景**: 实时控制、性能敏感应用

## 核心功能

| 模块 | 功能说明 |
|------|----------|
| 系统管理 | 连接/断开机器人、日志、重启 |
| 状态机 | 位置/阻抗/拖拽/释放等模式切换 |
| 实时反馈 | 1 kHz 实时数据（关节位置/速度/力矩） |
| 参数管理 | 读写整型/浮点型/字符串参数 |
| 运动学 | 正/逆运动学、MoveJ/MoveL 规划 |
| 末端通信 | CAN FD / RS485 外设通信 |

## 支持的机器人型号

- **Marvin Pro M3/M6**: 使用 SDK 03 版本
- **Gento Skye/Luna**: 使用 SDK 04 版本
