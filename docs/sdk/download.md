# SDK 下载

## SDK 04 - Gento 产品线

适用于 Gento Skye、Gento Luna 等型号，需要烧录 04 版本固件。

**GitHub 仓库**: [tianji-robot-SDK](https://github.com/tianjizn/tianji-robot-SDK)

**分支**: 

```bash
git clone -b Gento_Skye+Luna git@github.com:tianjizn/tianji-robot-SDK.git
```

## SDK 03 - Marvin 产品线

适用于 Marvin Pro 等型号，需要烧录 03 版本固件。

**GitHub 仓库**: [tianji-robot-SDK03](https://github.com/tianjizn/tianji-robot-SDK03)

**分支**: 

```bash
git clone -b Marvin_Pro git@github.com:tianjizn/tianji-robot-SDK03.git
```

## 包含内容

| 文件夹 | 说明 |
|--------|------|
| PYTHON_SDK/ | Python 开发包 |
| C_SDK/ 或 contrlSDK/ | C++ 控制 SDK |
| kinematicsSDK/ | 运动学 SDK |
| DEMO_C++/ | C++ 示例代码 |
| DEMO_PYTHON/ | Python 示例代码 |
| CommonConfig/ | 配置文件 |
| MarvinPlatform/ | 平台软件 |

## 平台软件

Windows 和 Linux 平台软件请在仓库的  或对应文件夹中查找。
